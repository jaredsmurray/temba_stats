Use IntroStatGPT

Create, organize, and compile statistical output

IntroStatGPT lets you request statistical tables and graphs in ordinary language. Begin after you install and set up IntroStatGPT.

This page explains the IntroStatGPT workflow: create outputs, view the gallery, organize the report, and compile a Word document. For guidance on writing precise requests and checking the resulting analysis, see Working with IntroStatGPT and Codex.

Find the available data

Each IntroStatGPT folder contains the data for its activity. To see what is available, send:

What datasets are available in this workspace? Give me their names and a short description of the variables in each. Do not begin an analysis.

You can then refer to a dataset by the name IntroStatGPT reports. IntroStatGPT will locate the corresponding file.

Request an analysis

Describe the statistical output you want. For example:

Using the Austin housing data, restrict attention to ZIP code 78752. Make a histogram of sale price and a table containing the sample size, mean, median, standard deviation, and IQR.

IntroStatGPT creates the requested outputs and shows them in the conversation. Outputs receive short identifiers:

  • P1, P2, … for plots
  • T1, T2, … for tables
  • R1, R2, … for regression output

Use these identifiers when requesting changes. IntroStatGPT creates statistical output; you are responsible for interpreting the results and writing conclusions.

Revise an output

For example:

Revise P1 to use 30 bins and format the horizontal axis as dollars.

This replaces the current version of P1. To retain both versions, request a fork:

Fork P1. Keep the existing version and create a new version with 30 bins.

The new output receives a new identifier.

Open the analysis gallery

Send:

Open the analysis gallery.

IntroStatGPT refreshes the gallery and returns an Open the analysis page link. Select it to open a live view of your current tables and plots.

The gallery has four filters:

  • All
  • In report
  • Not in report
  • Archived

If you close the gallery, ask IntroStatGPT to open it again.

Organize your work

Send:

Open the analysis organizer.

The organizer appears in the conversation. Use it to:

  • add or rename report sections;
  • move outputs between sections;
  • reorder outputs;
  • include or exclude outputs from the report; and
  • archive outputs you no longer need.

Moving an output does not include it in the report. Use Include in report for every output you want in the Word document.

When finished, select Apply organization and wait for IntroStatGPT to confirm that it saved the changes.

Create a Word report

Prepare the report

Send:

Prepare the report for review.

IntroStatGPT preserves the selected outputs, checks their placement, displays the report outline, and provides an approval token. Review the section and output order before approving it.

If the outline is incorrect, return to the organizer, make the correction, and prepare the report again.

Approve compilation

When the outline is correct, reply with the exact approval requested by IntroStatGPT. For example:

Approve report token ABC123.

Use the token IntroStatGPT provides for your report. IntroStatGPT creates a Word document in the reports folder and reports its location.

The document contains the report title, section headings, selected tables and plots, and space for your writing. Add your interpretations and conclusions in Microsoft Word.

Troubleshooting

The analysis gallery does not open

Send:

Refresh the analysis gallery and give me a clickable Open the analysis page link. Do not open its source code.

The organizer does not appear

Send:

Open the analysis organizer directly in this conversation. Do not open its HTML source in the editor.

Organizer changes are missing

Send:

Check the current analysis-board revision, refresh the gallery, and give me the updated analysis-page link.

Report preparation fails

A selected output may still be in Unassigned. Open the organizer, move it into a named section, apply the organization, and prepare the report again.

You are unsure what was saved

Send:

Tell me the current analysis-board revision, report selections, and section order.
